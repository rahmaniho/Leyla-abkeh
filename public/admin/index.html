راهنمای مدیر سایت

📱 نصب روی گوشی

  • اندروید (Chrome): منوی ⋮ → «افزودن به صفحۀ اصلی» یا «نصب برنامه»
  • آیفون (Safari): دکمۀ اشتراک‌گذاری ← «Add to Home Screen / افزودن به صفحۀ اصلی»
پس از نصب، آیکن «مدیریت سایت» کنار برنامه‌ها می‌نشیند و تمام‌صفحه باز می‌شود.

🚀 راه‌اندازی اولیه (یک‌بار)

  1. Netlify → سایت → Identity → Enable Identity
  2. Identity → Services → Git Gateway → Enable
  3. Identity → Invite users → ایمیل مدیر را وارد کنید
  4. لینک دعوت در ایمیل را باز کنید و رمز بسازید
راهنمای کامل: docs/CMS-SETUP.md

✍️ گردش‌کار روزانه

  1. مقالۀ تازه → پیش‌نویس → «آمادۀ انتشار»
  2. انتشار → یک کامیت روی main → سایت خودکار به‌روز می‌شود (معمولاً کمتر از ۲ دقیقه)
  3. اشتباه را می‌توان با «بازگردانی» همان کامیت اصلاح کرد؛ همه‌چیز در تاریخچۀ Git باقی است
