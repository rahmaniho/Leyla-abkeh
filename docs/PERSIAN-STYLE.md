# راهنمای زبان و رسم‌الخط فارسی سایت

این سند قاعده‌های نگارش متن‌های سایت (مقالات، صفحات، فرم‌ها و پیام‌های رابط کاربری) را
تعیین می‌کند. هدفش دو چیز است: یکدستی متن در همهٔ صفحه‌ها، و دور ماندن از نثر اداری عربی
که خواندنش برای مخاطب فارسی‌زبان دشوار است.

> این قاعده‌ها خودکار سنجیده می‌شوند: `tests/persian-style.test.ts` و
> `tests/typography.test.ts`. تغییر آگاهانهٔ قاعده‌ها باید همراه با به‌روزرسانی همین
> سند و آزمون‌ها باشد.

## ۱. کسرهٔ اضافه پس از «ه»

| نادرست | درست |
| --- | --- |
| پروندهٔ | **پروندهی** |
| مادهٔ ۲۲ | **مادهی ۲۲** |
| جلسهٔ اول | **جلسهی اول** |
| همۀ موارد | **همهی موارد** |
| در رابطه با | **دربارهی** |

- شکل «ۀ» (U+06C0) و «هٔ» (ه + U+0654) هر دو ممنوع‌اند؛ شکل نخست همزهٔ عربی است و
  شکل دوم دو نویسهٔ جداست که در فونت‌های B ممکن است به فونت پشتیبان بیفتد و
  ناهم‌خوان دیده شود.
- «هی» به هم چسبیده نوشته می‌شود، بدون فاصلهٔ مجازی: «پروندهی»، نه «پرونده‌ی».

## ۲. نویسه‌ها

- فقط نویسه‌های فارسی: **ی** (U+06CC) و **ک** (U+06A9).
- نویسه‌های عربی ممنوع: `ي` (U+064A)، `ك` (U+0643)، `ة` (U+0629)، `ى` (U+0649).
- نیم‌فاصله (ZWNJ) در واژه‌های مرکب: «می‌شود»، «پرونده‌های»، «به‌صورت».

## ۳. رقم و نشانه‌گذاری

- در متنِ قابل‌مشاهده، رقم فارسی: ۲۳۷۰، ۱۱۰، ۱۴۰۵. رقم لاتین فقط در مسیر فایل،
  کد و شمارهٔ فهرست Markdown.
- ویرگول فارسی «،» و نقطه‌ویرگول «؛» و علامت سؤال «؟»؛ نه `,` و `;` و `?`.
- پیش از نشانه‌ها فاصله نمی‌آید: «پرونده،» نه «پرونده ،».
- جمله‌ها با «.» تمام می‌شوند؛ سه‌نقطه به‌شکل «…».

## ۴. نثر: فارسی روان، نه اداری

این عبارت‌ها در متن سایت جایی ندارند؛ جایگزین فارسی‌شان نوشته می‌شود:

| به‌جای | بنویسید |
| --- | --- |
| می‌باشد / می‌باشند | است / هستند |
| می‌گردد / گردید | می‌شود / شد |
| لذا / لکن | پس / اما |
| بدین‌وسیله / بدین‌جهت | با این یادداشت / برای همین |
| مبادرت کرد | اقدام کرد |
| اقدام به عمل آمد | انجام شد |
| صورت پذیرفت | انجام شد |
| در راستای | برای |
| در خصوص / در رابطه با | دربارهی / در این باره |
| لازم به ذکر است / قابل ذکر است | (حذف شود) |
| متعاقباً | پس از آن |
| اینجانب | من / این دفتر |
| فیمابین | میان |
| حاصله | به‌دست‌آمده |

اصطلاح‌های **حقوقی** استثنا هستند و همان‌جا می‌مانند: «مستند به»، «مبنی بر»،
«لازم‌الاجرا»، «مقرر می‌دارد» (در نقل قانون)، «محکوم‌له»، «اعسار»، «تقسیط».

## ۵. ساختار مقاله

هر مقاله سه لایه دارد و لایهٔ اول برای خوانندهٔ عجول و برای موتور پاسخ‌دهنده است:

1. **پاسخ کوتاه** — دو تا چهار جمله، بدون مقدمه‌چینی.
2. **بدنه** — سرفصل‌های `##` و `###` با عبارت واقعی جست‌وجو، جدول یا فهرست در جای لازم.
3. **سؤالات متداول** — همان بخشی که `FAQPage` از آن ساخته می‌شود؛ پرسش‌ها باید
   همان چیزی باشند که کاربر واقعاً می‌پرسد.

و در پایان: **منابع قانونی** (مواد مشخص) و **نتیجه**.

## ۶. چیزهایی که نوشته نمی‌شود

- آمار، نرخ موفقیت، تعداد پرونده یا نظر موکل بدون سند.
- تضمین نتیجه («پروندهٔ شما برنده است»).
- رتبه‌بندی خودساخته («بهترین وکیل») به‌عنوان ادعای رسمی.
- متن پنهان، تکرار کلیدواژه در حاشیه، یا هر شکلی از cloaking برای موتور جست‌وجو.
- تعرفهٔ قطعی پیش از تأیید دفتر.
